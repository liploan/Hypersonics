# GitHub Pages Interactive Web Studio (`docs/`)

This folder is served directly by GitHub Pages at **https://liploan.github.io/Hypersonics/** (with `.nojekyll` enabled) and requires zero bundlers or external CDN dependencies.

---

## Pages & Modules

- **[`index.html`](index.html)** — Interactive 6-panel Hypersonic Watertight Waverider, Conventional Reentry Vehicle (RV) & UHF–X Band RCS Studio:
  1. Interactive 3D watertight mesh viewport with orbit/zoom, attached/bow shock wave sheet, and concave double-bounce ray overlays (ventral waverider cavities, recessed RV aft domes, and flared RV conic junctions)
  2. Cross-sectional trailing-edge/frustum contour view (Waverider tab) or dimensioned meridional $X$–$R$ outer-mold-line & aft-cavity blueprint (Reentry Vehicle tab)
  3. Multi-band azimuthal monostatic RCS ($\psi \in [0^\circ, 180^\circ]$ across UHF $0.5$, L $1.5$, S $3.0$, C $6.0$, and X $10.0\text{ GHz}$)
  4. Ventral ($\theta_{\text{el}} < 0^\circ$) vs. dorsal ($\theta_{\text{el}} > 0^\circ$) elevation cut comparing total (Gordon PO + GO-PO 2-bounce) against single-bounce PO
  5. Interactive 2D Range–Angle–Intensity (RTI) radar sinogram with nose/base/booster range loci and click-to-slice azimuth cursor
  6. 1D High-Resolution Range Profile (HRRP) cut decomposing direct PO returns and $+0.5\,d_{PQ}$ delayed cavity returns
- **[`references.html`](references.html)** — Searchable, discipline-filterable 24-citation primary bibliography with verified DOIs/NASA NTRS links, source-code cross-reference chips, and 1-click BibTeX copy buttons.
- **[`physics.js`](physics.js)** — Standalone UMD physics engine (`window.WaveriderPhysics` / `module.exports`) verified by [`tests/web/validate_physics.mjs`](../tests/web/validate_physics.mjs).
- **[`app.js`](app.js)** — UI controller, physical slider guardrail enforcer, tiered `requestAnimationFrame` scheduler, Canvas renderers, and STL/OBJ/MATLAB exporters.
- **[`styles.css`](styles.css)** — Responsive dark/light stylesheet meeting WCAG AA contrast ($\ge 4.5:1$).
- **[`assets/`](assets/)** — High-resolution verification figures generated by MATLAB R2026b.
